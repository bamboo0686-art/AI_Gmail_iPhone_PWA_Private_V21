AI 個人 Gmail 智慧註冊代理中心｜iPhone PWA 私有直接使用版 V20

重要：
1. 這不是 IPA，也不需要 Mac 或 App Store。
2. 必須把整個資料夾部署到 HTTPS 網址。
3. iPhone 用 Safari 開啟該網址。
4. 點 Safari「分享」→「加入主畫面」→「加入」。
5. 之後桌面會出現 Gmail AI Agent 圖示，可像 App 一樣全螢幕使用。
6. 第一次成功開啟後，Service Worker 會快取核心檔案，可支援離線開啟。
7. 任務資料預設存在 iPhone Safari / PWA 的 LocalStorage。
8. 清除 Safari 網站資料可能會刪除本機資料，請定期使用「匯出備份」。

- CAPTCHA：Human Gate
- OTP：Human Gate
- Google 本人／安全驗證：Human Gate
- 不做風控、代理、裝置指紋或限制規避
